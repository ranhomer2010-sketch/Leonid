# Редактор сайта Леонида Агафонова

Адрес после установки на PHP-хостинг: `https://ВАШ-ДОМЕН/admin/`.
GitHub Pages показывает статический сайт и не исполняет PHP.

## Что можно менять

- Тексты всех разделов и настройки для поисковиков.
- Названия, описания, длительность и стоимость услуг; можно добавлять и удалять строки. На сайте подробный прайс открывается по нажатию на направление, стартовая цена пересчитывается автоматически.
- Контактные ссылки сразу во всех кнопках сайта.
- События на главной: название, тип, дата, место, описание, ссылка, афиша и видимость.
- Документы: название, подпись, изображение и видимость; новые сертификаты можно добавлять и удалять.
- Отзывы: ссылки на публикации, подписи и видимость. Переход ведёт к первоисточнику.
- Дополнительные разделы: заголовок, текст, фото, кнопка и видимость.
- Два фото Леонида, фотографии кабинета и карточек навигации.
- Пароль администратора.

При сохранении редактор записывает `content/site.json` и пересобира публичный `index.html` из `site.template.html`. Перед сохранением он создаёт резервную копию данных в `admin/private/backups` (до 20 копий).

## Установка

1. Используйте готовый пакет с индивидуальным файлом `admin/private/auth.php`. Этого файла нет в публичном GitHub-репозитории.
2. Распакуйте содержимое архива в корень сайта на российском PHP-хостинге с HTTPS. После распаковки удалите ZIP из публичной папки. Нужен PHP 8.0+ с расширениями `fileinfo`, `json` и поддержкой загрузки файлов. Предполагается Apache 2.4 с `.htaccess`.
3. Убедитесь, что PHP может записывать `index.html`, `content/site.json`, `admin/private/` и `assets/uploads/`.
4. Откройте `/admin/`, войдите по выданному паролю и сразу смените его внизу страницы.
5. В разделе «Настройки сайта» замените адрес GitHub Pages на адрес нового домена. Это нужно для поисковых метаданных и фотографии при отправке ссылки.

Раздел «Ближайшие события» и его карточка на главном экране видны всегда. Если событий нет, показывается сообщение. После публикации карточка ведёт по ссылке события; если ссылка не указана, она ведёт к афише, а карточка внутри афиши — к каналу анонсов. Событие можно сохранить скрытым и показать позднее. Для будущих направлений предусмотрены дополнительные блоки. Фотографии документов публикуются без изменения текста и печатей; посетитель может открыть полное изображение.

Файл `auth.php` нельзя размещать в публичном репозитории. Не загружайте реальные заявки на этот сайт: форма обратной связи здесь не используется, запись ведёт в Telegram.
