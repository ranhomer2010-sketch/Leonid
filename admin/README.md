# Редактор сайта Леонида Агафонова

Адрес после установки на PHP-хостинг: `https://ВАШ-ДОМЕН/admin/`.
GitHub Pages показывает статический сайт и не исполняет PHP.

## Что можно менять

- Основные тексты по разделам.
- Названия, описания, длительность и стоимость услуг; можно добавлять и удалять строки.
- Портрет и две фотографии кабинета.
- Пароль администратора.

При сохранении редактор записывает `content/site.json` и пересобира публичный `index.html` из `site.template.html`. Перед сохранением он создаёт резервную копию данных в `admin/private/backups` (до 20 копий).

## Установка

1. Используйте готовый пакет с индивидуальным файлом `admin/private/auth.php`. Этого файла нет в публичном GitHub-репозитории.
2. Распакуйте содержимое архива в корень сайта на российском PHP-хостинге с HTTPS. После распаковки удалите ZIP из публичной папки. Нужен PHP 8.0+ с расширениями `fileinfo`, `json` и поддержкой загрузки файлов. Предполагается Apache 2.4 с `.htaccess`.
3. Убедитесь, что PHP может записывать `index.html`, `content/site.json`, `admin/private/` и `assets/uploads/`.
4. Откройте `/admin/`, войдите по выданному паролю и сразу смените его внизу страницы.

Файл `auth.php` нельзя размещать в публичном репозитории. Не загружайте реальные заявки на этот сайт: форма обратной связи здесь не используется, запись ведёт в Telegram.
